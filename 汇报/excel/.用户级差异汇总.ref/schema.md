# Workbook Design — 用户级差异汇总

> 由 excel-generation skill 在主代理侧产出，供 sheet-agent 子代理按图施工。

## User Intent
将《金额差异对比分析报告》第六章 §6.2「用户级差异汇总」表单独抽取为一份 Excel，保存到 `汇报/excel` 目录下。

## Scenario Archetype
- 统计型 + 记录型：用户级金额差异的静态汇总表，数据量小（12 用户 + 1 合计行），单 sheet 即可；差异/差异率可公式化。

## Sheets
- `用户级差异汇总`（主表：用户级金额差异汇总）

## Sheet: 用户级差异汇总

### Columns
| 列 | 字段名 | 类型 | 来源 | 备注 |
|---|---|---|---|---|
| A | 用户 | 文本 | reference/金额差异对比分析报告/content.md §6.2 | 12 个用户名，左对齐；A14 = "合计" |
| B | 积分消耗 | 数字（0位小数） | reference/金额差异对比分析报告/content.md §6.2 | 整数，千位分隔符 `#,##0`；B2:B13 为原始数据；B14：`=SUM(B2:B13)` |
| C | 积分金额(元) | 数字（2位小数） | reference/金额差异对比分析报告/content.md §6.2 | 格式 `#,##0.00`；C2:C13 为原始数据；C14：`=SUM(C2:C13)` |
| D | 厂商扣费(元) | 数字（2位小数） | reference/金额差异对比分析报告/content.md §6.2 | 格式 `#,##0.00`；D2:D13 为原始数据；D14：`=SUM(D2:D13)` |
| E | 差异(元) | 数字（2位小数） | 计算列 | 格式 `#,##0.00`；E2：`=C2-D2`，填充 E2:E13；E14：`=SUM(E2:E13)` |
| F | 差异率 | 百分比 | 计算列 | 格式 `0.00%`；F2：`=IF(OR(D2="",D2=0),"",E2/D2)`，填充 F2:F13；F14：`=IF(OR(D14="",D14=0),"",E14/D14)` |

### Sample Data Scale
- 12 行真实数据（来自 reference 数据表）+ 1 行合计 = 13 行数据。

### Notes for sheet-agent
- 第 1 行：表头，商务蓝 `#4472C4` 底 + 白字 `#FFFFFF` + 加粗 + 水平居中 + 下边框 thin。
- 第 2~13 行：用户数据行；文本列左对齐，数字列右对齐。
- 第 14 行：合计行，加粗 + 上边框 thin + 深蓝 `#2F5597` 底 + 白字（汇总区）。
- 所有 `来源=计算列` 的字段，按 Columns 表"备注"中的公式执行；填充范围 E2:E13 / F2:F13，合计公式写入 E14 / F14；验证时读回公式文本确认除零保护。
- 条件格式：E2:E14（差异(元)）与 F2:F14（差异率）中数值 < 0 → 红字 `#9C0006`（负值/异常高亮）。
- 可用性：B 列千位分隔符；C/D/E 列保留两位小数；F 列百分比两位小数；所有数值列右对齐。
- 参考数据以 reference/金额差异对比分析报告/content.md §6.2 表格为准，其中"积分金额(元)""厂商扣费(元)"为原始数据，"差异(元)""差异率"两列数值仅作核对参考，最终以公式计算结果为准（差异率按各自行真实值计算，个别行与参考展示值可能存在末位舍入差）。

## Charts / Pivots
无

## 约束与不做的事
- 不做图表、不做透视表、不添加其他 sheet；
- 不包含报告其他章节内容（如异常清单、数据源说明等）；
- 不合并单元格（普通数据表）。
